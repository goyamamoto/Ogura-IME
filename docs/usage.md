# 使い方

## キー操作

既定の MS-IME 互換モードでの操作です。設定「入力」>「変換のキー操作」で macOS 標準（azooKey と同じ）に切り替えられます。


| キー                       | 入力中                                                                                   | 変換中・候補選択中           |
| ------------------------ | ------------------------------------------------------------------------------------- | ------------------- |
| Space / Shift+Space      | 変換                                                                                    | 次候補 / 前候補           |
| ↓ / ↑                    | 変換                                                                                    | 次候補 / 前候補           |
| Enter                    | 確定                                                                                    | 選択中の候補と残りの文節をまとめて確定 |
| Ctrl+Enter / Ctrl+M      | 確定                                                                                    | 同上                  |
| BackSpace / Delete       | 1文字削除                                                                                 | 変換を取り消してひらがなに戻す     |
| Esc / Ctrl+Z / Ctrl+G    | 入力を全消去                                                                                | 候補一覧を閉じる → ひらがなに戻す  |
| Shift+← / Shift+→        | 文節を縮める / 伸ばす                                                                          | 同左                  |
| Ctrl+K / Ctrl+L          | 文節を縮める / 伸ばす                                                                          | 同左                  |
| Ctrl+E / Ctrl+X          | ―                                                                                     | 前候補 / 次候補           |
| Ctrl+N / →               | ―                                                                                     | 先頭文節を確定して次の文節へ      |
| F6 / Ctrl+U              | ひらがな                                                                                  | 同左                  |
| F7 / Ctrl+I              | 全角カタカナ                                                                                | 同左                  |
| F8 / Ctrl+O              | 半角カタカナ                                                                                | 同左                  |
| F9 / Ctrl+P              | 全角英数                                                                                  | 同左                  |
| F10 / Ctrl+T             | 半角英数                                                                                  | 同左                  |
| Tab                      | 予測候補を受け入れる（設定の「予測入力（開発中）」がオンのとき）                                              | ―                   |
| Ctrl+Delete              | ―                                                                                     | 選択中の候補の学習を忘れる       |
| 英数キー 2回                  | 入力中の文字を半角英数で確定して英字モードへ                                                                | 同左                  |
| Shift+Tab / Ctrl+/ / F19 | 続きを書く（提案を薄く表示。Tab / Enter で確定、Esc で破棄）。3 つのキーは設定で個別にオン・オフできる。F19 はキーボード側で好きなキーに割り当てる用 | 未確定文字列を確定してから続きを書く  |


入力がない状態では Ctrl 系のキーはすべてアプリ側に渡るので、Ctrl+Z などのアプリのショートカットを妨げません。

## 設定

メニューバーの入力メニュー >「設定…」から開きます。


| タブ  | 内容                                                                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------- |
| 変換  | ライブ変換、変換プロフィール（Zenzai に渡す自己紹介文）、履歴学習の有効・無効とリセット                                                                        |
| 入力  | ローマ字 / かな入力、ローマ字テーブルのカスタマイズ、キーボード配列、変換のキー操作（MS-IME / macOS）、句読点、先頭大文字での英字入力、日本語らしくない入力での英字の候補、英単語とローマ字の見分けに学習モデルを使うか（試用中）、半角スペース、記号の半角入力（英単語や数字の後の - も半角）、バックスラッシュ、Option キーでの全角英数入力          |
| 辞書  | ユーザ辞書の編集、macOS ユーザ辞書の取り込み                                                                                              |
| 詳細  | Zenzai の推論上限、Tuner の個人最適化、予測入力（開発中）、続きを書く（オフ / Apple の端末内モデル / Mac 内の MLX モデル、モデルの選択、きっかけにするキーの選択）、データフォルダを Finder で開く |
