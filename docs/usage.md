# 使い方

## キー操作

既定の MS-IME 互換モードでの操作です。設定「入力」>「変換のキー操作」で macOS 標準（azooKey と同じ）に切り替えられます。


| キー                       | 入力中                                                                                   | 変換中・候補選択中           |
| ------------------------ | ------------------------------------------------------------------------------------- | ------------------- |
| Space / Shift+Space      | 変換                                                                                    | 次候補 / 前候補           |
| ↓ / ↑                    | 変換                                                                                    | 次候補 / 前候補           |
| Enter                    | 確定                                                                                    | 選択中の候補と残りの文節をまとめて確定 |
| Ctrl+Enter / Ctrl+M      | 確定                                                                                    | 同上                  |
| BackSpace / Delete       | 1文字削除                                                                                 | 変換を取り消してひらがなに戻す     |
| Esc / Ctrl+Z / Ctrl+G    | ひらがなに戻す（もう一度押すと全消去。ライブ変換がオフのときは全消去）                                   | ひらがなに戻す             |
| Shift+← / Shift+→        | 文節を縮める / 伸ばす                                                                          | 同左                  |
| Ctrl+K / Ctrl+L          | 文節を縮める / 伸ばす                                                                          | 同左                  |
| Ctrl+E / Ctrl+X          | ―                                                                                     | 前候補 / 次候補           |
| → / Ctrl+N / Ctrl+D      | → は読みの中でカーソルを右へ（ライブ変換の表示はひらがなに戻る。その位置で打ち足し・削除ができ、Space で全体を変換）。Ctrl+N / Ctrl+D は ― | 次の文節へ（確定しない）        |
| ← / Ctrl+S               | ← は読みの中でカーソルを左へ（同上）。Ctrl+S は ―                                                      | 前の文節へ               |
| 1〜9                      | ―                                                                                     | 番号の候補を選んで次の文節へ      |
| F6 / Ctrl+U              | ひらがなにする（確定は Enter）                                                                        | 文節をひらがなにする         |
| F7 / Ctrl+I              | 全角カタカナにする（同上）                                                                           | 文節を全角カタカナにする       |
| F8 / Ctrl+O              | 半角カタカナにする（同上）                                                                           | 文節を半角カタカナにする       |
| F9 / Ctrl+P              | 全角英数にする（同上）                                                                             | 文節を全角英数にする         |
| F10 / Ctrl+T             | 半角英数にする（同上）                                                                             | 文節を半角英数にする         |
| Tab                      | 予測候補を受け入れる（設定の「予測入力（開発中）」がオンのとき）                                              | ―                   |
| Ctrl+Delete              | ―                                                                                     | 選択中の候補の学習を忘れる       |
| 英数キー 2回                  | 入力中の文字を半角英数で確定して英字モードへ                                                                | 同左                  |
| Caps Lock                | macOS の「Caps Lock キーで入力ソースを切り替える」設定（システム設定 > キーボード > 入力ソース）がオンなら、短く押すと日本語と英字の入力ソースを切り替え、長押しで Caps Lock。スペースで区切った英文を打つとき用 | 同左                  |
| Shift+Tab / Ctrl+/ / F19 | 続きを書く（提案を薄く表示。Tab / Enter で確定、Esc で破棄）。3 つのキーは設定で個別にオン・オフできる。F19 はキーボード側で好きなキーに割り当てる用 | 未確定文字列を確定してから続きを書く  |


入力がない状態では Ctrl 系のキーはすべてアプリ側に渡るので、Ctrl+Z などのアプリのショートカットを妨げません。

## 変換の表示

ライブ変換では、キーを押すとすぐ表示し（直前の変換に、そのあと打った読みを足したもの）、変換が届いたら表示を直します。打鍵が 0.2 秒止まると、入力全体をもう一度変換し直して（徹底変換）、違う結果ならその場で表示を置き換えます。Enter はそのとき表示している変換を確定し、Space は表示している変換をそのまま文節に分けます。変換が届く前に押した Enter と Space は、入力全体を変換してから働きます。→ で文節を移っても、残りの文節の表示は変わりません。

入力が長くなると、前のほうを自動で確定します。終わりの 60 文字は、戻って直せるようにいつも未確定のまま残し、その手前の切りのいいところ（文末、なければ読点）までを確定します。キーを押しっぱなしにしたときなど、変換が打鍵に大きく遅れたときは、変換が追いつくまで文字のキーを受け付けません。詳しくは[かな漢字変換](conversion.md)を参照してください。

F6〜F10 は MS-IME と同じく確定しません。続けて押すと、カタカナやひらがなは末尾から一文字ずつ元の形に戻り（トウキョウ → トウキョう）、英数は「打ったまま → 大文字 → 先頭だけ大文字」と変わります。macOS 標準の設定ではその場で確定します。

## 設定

メニューバーの入力メニュー >「設定…」から開きます。


| タブ  | 内容                                                                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------- |
| 変換  | ライブ変換、変換プロフィール（Zenzai に渡す自己紹介文）、履歴学習の有効・無効とリセット                                                                        |
| 入力  | ローマ字 / かな入力、ローマ字テーブルのカスタマイズ、キーボード配列、変換のキー操作（MS-IME / macOS）、句読点（英字や数字の間のピリオドとカンマ、英単語や数字の後の - は半角）、先頭大文字での英字入力、日本語らしくない入力での英字の候補、英単語とローマ字の見分けに学習モデルを使うか（既定でオン）、半角スペース、記号の半角入力、バックスラッシュ、Option キーでの全角英数入力          |
| 辞書  | ユーザ辞書の編集、macOS ユーザ辞書の取り込み                                                                                              |
| 詳細  | Zenzai のモデル（genmai / zenz-v3.2-small。[かな漢字変換](conversion.md)を参照）、Zenzai の推論上限、Tuner の個人最適化、予測入力（開発中）、続きを書く（オフ / Apple の端末内モデル / Mac 内の MLX モデル、モデルの選択、きっかけにするキーの選択）、データフォルダを Finder で開く |
